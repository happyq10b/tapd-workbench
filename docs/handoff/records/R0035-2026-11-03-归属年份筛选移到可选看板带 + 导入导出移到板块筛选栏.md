#### 宽度重算（这一步不能拍脑袋）

导入导出移进工具栏后，`.toolbar-right` 里多了第 4 个按钮，原锁 287px 不够 →
按钮被压缩 → **文字折行**（「导入导出」变成上下两行）。

实测各按钮的**自然宽度**（`scrollWidth`，即不被压缩时的需求）：

| 按钮 | 自然宽 |
|---|---|
| ＋ 新建板块 | 97px |
| 展开板块 | 84px |
| 折叠板块 | 84px |
| 🔄 导入导出 | 105px |
| **合计** | **370px** |
| + 3×gap(8) | **394px** |

→ 锁 **400px**（394 + 6px 余量）。
**中途试过 360px，差 34px → 「编辑/导入导出」仍折行** —— 差几像素最容易漏。
另加 `.toolbar-right .btn-default{white-space:nowrap;flex-shrink:0}` 兜底：
即使将来再加按钮，文字也不会折行（宁可溢出也不折行）。
