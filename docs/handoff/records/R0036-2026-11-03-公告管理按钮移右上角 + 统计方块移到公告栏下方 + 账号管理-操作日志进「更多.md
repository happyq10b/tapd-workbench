#### ① 公告管理按钮移到右上角

**障碍**：公告栏标题原是 `::before` 伪元素画的「公告」两字 —— **伪元素里放不下按钮**。

**改法**：伪元素标题改为**真实 DOM 标题行**：

```html
<div class="notice-head">
  <span class="t">📢 公告</span>
  <button class="btn-default notice-mgr" onclick="openNoticeModal()">管理公告</button>
</div>
```

- CSS：`.notice-bar::before{display:none}`（避免重复标题）+ 新增 `.notice-head` 标题行样式
- JS：`renderNoticeBar()` 里新增 `head` 变量，**有公告 / 无公告两个分支都套上**
- 空态文案同步改：「可点击右侧「管理公告」发布」→「可点击**右上角**「管理公告」发布」

#### ② 统计方块移到公告栏下方

**改法**：`.tb-stat-band` 从 `.topbar-main` 移到 `.topbar-aside` 内、公告栏之后。
右半变成竖排「公告栏 + 统计带」。

**宽度要求「不超过公告栏」天然满足**：两者同属 `.topbar-aside` 这一列，
宽度由该列宽（`minmax(300px,420px)`）决定 → 实测统计带 420px = 公告栏 420px，**未超出**。

**「公告栏要高点，正好把空部分用完」**（用户中途追加）：
`.notice-bar` 保持 `flex:1` → 吃掉右半除统计带外的**全部剩余高度**，
与左半等高（`.topbar` 的 `align-items:stretch`）；统计带 `flex-shrink:0` 固定在下方。

> ⚠️ 中途我一度改成 `flex:0 1 auto; max-height:220px` + `align-self:start`，
> 结果右半底部空了 170px —— 用户一句「正好把空部分用完」点醒了方向，已改回。

**统计卡窄版**：每格宽度只有 ~130px（原左半 ~300px），
原 `padding:8px 14px` + 20px 字号会挤 → 窄版 `padding:7px 10px` + 16px 字号，
另把 `@media(≤640px)` 与 `@media(≤1199px)` 里的字号规则**同步为 16px**（否则会覆盖窄版）。
