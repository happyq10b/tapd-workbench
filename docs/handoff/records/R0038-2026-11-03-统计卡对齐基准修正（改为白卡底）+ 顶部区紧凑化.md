#### 🔴 关键：#37 的对齐基准搞错了

#37 我把统计带底对齐到「**可选看板带**的底边」（358px），用 `margin-bottom:34px` 抵消。
但用户要的基准是**左侧白底卡片（`.tb-navgroup`）的底边**（367px）——
「可选看板带」与「白卡底」之间还差 **9px**（navgroup 的 `padding-bottom:8px` + 边框 1px）。

**我上一轮把「带底」当成了对齐目标 → 对齐到了错误的位置。**

#### ✅ 修正：改用「天然对齐」，不需要任何偏移量

`.topbar` 是两列 grid + `align-items:stretch` → 左右两列底边**天然齐平**：

```
左侧 navgroup 底 = .topbar-main 底（main 唯一子项就是 navgroup）
右侧 统计带底  = .topbar-aside 底（统计带是 aside 最后一个子元素）
两者 = topbar 底 → 自动相等
```

**改法**：删掉 `.topbar-aside` 的 `margin-bottom:var(--topbar-aside-bottom-offset)`，
并删除该变量及其注释里的偏移逻辑。

实测：**卡片底(367) − 白卡底(367) = 0px**；
「卡片底 − 可选看板带底 = 9px」= 白卡内部下留白 → 证明对齐的是**白卡**而非带。

  **统计卡底 → 工具栏顶的间距 50px → 12px**（34 margin + 16 padding → 0 + 12）。
