#### ① 主页按钮靠右

`.tree-dept` 已是 `inline-flex` 且作为 grid item 撑满 303px 列宽，
但 `.dept-home` 用 `margin-left:2px` 紧跟部门名 → 右边空 146~159px。

**改法**：`margin-left:2px` → `margin-left:auto`（flex 内自动吸收剩余空间）。
实测：距部门块右缘 **146~159px → 16px**（= 块内 padding 14 + 边框 1 + 取整 1），
六个部门整齐对齐在同一竖线上。

#### ② 统计卡底边与「可选看板」底边对齐

**根因**：`.topbar` 是两列 grid（`align-items:stretch`），左右两列都被拉到 topbar 底。
但左半 `.topbar-main` 是 grid 且声明了 `grid-template-rows:auto auto auto`，
**实际只有 1 个子项**（`.tb-navgroup`）→ 末尾产生 **2 个空行的 gap（10×2=20px）**；
`.tb-navgroup` 自身 `padding-bottom:13px` + 1px 边框
→ 「可选看板」带底比 topbar 底高 **34px**。右半的统计带紧贴 topbar 底 → 差 34px。

**改法**：`.topbar` 上定义 `--topbar-aside-bottom-offset:34px`，
`.topbar-aside` 加 `margin-bottom:var(--topbar-aside-bottom-offset)`。
grid item 在 stretch 时内容盒高 = grid area 高 − margin → 右半内容盒 317−34=283px，
统计带底正好落在 **358px = 可选看板带底**。

实测：**统计带底 − 看板带底 = 0px**（改前 34px）。

> ⚠️ 该值依赖 `.topbar-main` 的行数/gap 与 `.tb-navgroup` 的 padding-bottom，
> 改动这两处需同步（已写进 CSS 注释）。

#### ③ 公告标题字体对齐「架构部门」

`.notice-head .t` 原 `11.5px / 400 / var(--text3)`
→ 改为 `.tb-band-title` 同款 **`13px / 700 / var(--text2) / letter-spacing .4px`**。

实测 computed style 完全一致：
`13px/700/rgb(100,106,115)/0.4px`（两者相同）。

> 注：「架构部门」左侧有 `::before` 蓝色竖条，公告没有 ——
> 竖条属装饰非字体，用户只要求字体一致，故未加。

#### ④ 搜索栏加宽 + 消除右侧空白

**根因**：`.toolbar` 是 `flex-wrap:wrap`，`.toolbar-left{flex:0 0 875px}` +
`.toolbar-right{flex:0 0 400px}`，两者都**不 grow**。
1600px 视口下工具栏内宽 1360 > 875+400+10 = 1285 → **多出 75px 无处可去**，
表现为「导入导出」按钮右侧一条空白带。

**改法**：

| 项 | 改前 | 改后 | 理由 |
|---|---|---|---|
| `.toolbar-left` | `flex:0 0 875px` | **`flex:1 1 875px`** | 吸收剩余空间；其内**只有搜索框是 grow:1** → 由它吸收，其余控件宽度位置不变 |
| `.search-input` | `max-width:230px` | **`max-width:360px`** | 让搜索框能吃掉 grow 空间 |
| `.toolbar-right` | `flex:0 0 400px` | **`flex:0 0 402px`** | 原值比内容窄 2px（实测 99+86+86+107+3×8=402）→ 最后一个按钮溢出 2px |
| `.toolbar` | `min-width:1317px` | **`min-width:1319px`** | 875+402+10+32 |

实测：**导入导出右侧空白 72px → 1px**；搜索框 167 → **200px**；
1200px 基线**完全不变**（此时内容正好填满、无剩余 → left 仍 875px、搜索框仍 167px）。
