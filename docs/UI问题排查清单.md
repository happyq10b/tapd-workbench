## 一、✅ 已修：焦点可见性缺失

**原状**：45 个可聚焦元素中 **37 个没有可见焦点环**（82%）。

**根因**：`index.html` L980–981 的 `:focus-visible` 规则只点名了 6 个类：

```css
.btn-primary:focus-visible,.btn-default:focus-visible,.header-btn:focus-visible,
.tab-btn:focus-visible,.icon-btn:focus-visible{outline:none;box-shadow:var(--ring)}
.search-input:focus-visible,.form-input:focus-visible,...{outline:none}
```

**修法**：加**通用兜底**，而不是逐个点名：

```css
:where(button,a[href],input,select,textarea,[tabindex],[onclick]):focus-visible{
  outline:2px solid var(--primary);outline-offset:2px;border-radius:4px}
```

> `:where()` 的特异度为 0，不覆盖任何已有规则 → **安全**。  
> 已有个性化样式的（`.btn-*` 等）保持不变。  
> **实测**：65 个可聚焦元素，焦点环覆盖 **0 遗漏**。

## 三、✅ 已修：颜色对比度不足（WCAG AA）

**原状**：10 处文本对比度低于 AA。

**根因**：品牌绿 `#22c55e` 与品牌橙 `#f59e0b` 是**填充色**，被直接当作**文字色**使用。

**修法**：**只改文字色为同色相的深色变体**，背景色/边框色/填充色一律不动  
→ 语义识别（绿=完成、橙=未完成、红=逾期）**完全保留**，  
视觉上只是「颜色沉下去」，不会出现「标签变成另一种颜色」的错觉。

| 元素                       | 原色        | 新色        | 实测对比度  |
| ------------------------ | --------- | --------- | ------ |
| `.status-tag.done`       | `#22c55e` | `#17853f` | 4.58 ✓ |
| `.status-tag.pending`    | `#ef4444` | `#cb3939` | 4.56 ✓ |
| `.stat-value.green`      | `#22c55e` | `#178740` | 4.59 ✓ |
| `.stat-value.orange`     | `#f59e0b` | `#a46907` | 4.56 ✓ |
| `.stat-value.red`        | `#ef4444` | `#d73d3d` | 4.54 ✓ |
| `.role-admin`            | `#d46b08` | `#b25906` | 4.56 ✓ |
| `.lock-tag`（逾期）          | `#d48806` | `#a16704` | 4.53 ✓ |
| `.tree-dept.empty .chev` | `#d0d0d0` | `#727272` | 4.61 ✓ |
| `--text3`（灰阶统一）          | `#a8abb2` | `#73757a` | 4.61 ✓ |

> 💡 顺带收敛了「两套小字灰」：`#a8abb2` 与硬编码的 `#d0d0d0` 统一到 `--text3`。  
> ⚠️ **「逾期」标签原用行内 `style="color:var(--danger)"`** —— 行内样式优先级最高，

### 2. 架构部门排序「按部门名」实现（T-003）

当前用**纯 CSS `order` + `:nth-child`** 实现，映射依赖**后端返回的 DOM 序号**：

```
DOM 实测序：1 财务中心 / 2 核算部 / 3 总账部 / 4 管理部 / 5 资金部 / 6 商务部
映射：      nth-child(1)→视觉1、nth-child(6)→视觉2、nth-child(2)→视觉3 …
```

- CSS **无法按<u>文本选中元素</u>**<u>，纯 CSS 路径只能走 `:nth-child`。</u>
- **<u>若后端 `_dept_order()` 的顺序变化，这张映射表就失效</u>**<u>（视觉顺序会错乱）。</u>
- <u>若要「按部门</u>名排序」，需在 JS 侧按名排序 → 属逻辑层 → **主设计师**。
- 已登记 **T-003**。

## 附注：扫描器的两处方法学修正

排查过程中发现扫描器自身有误判，**已修正**（否则会把"改好了"报成"没改好"）：

| 问题                         | 现象                                                                                                    | 修正                                     |
| -------------------------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------- |
| **`forEach.call` 第三个参数**   | `Array.prototype.forEach.call(arr, 0, 80)` 的第三参是 **thisArg** 不是「取前 80 个」→ 传 0 使回调**静默不执行** → 焦点统计恒为 0 | 改用 `slice.call(arr,0,80).forEach(...)` |
| **`:focus-visible` 的触发条件** | `:focus-visible` **只对键盘导航激活**，程序化 `el.focus()` 不触发 → 早先版本把所有元素都误判为「无焦点环」                              | 改为**扫描样式表**判断覆盖关系，不依赖运行时 focus         |

另修正两处误报排除：  
① 纯文本 span（如 `.item-title`，宽 270px 但高 22px，是行内标题文字而非点击目标）  
② 已用 `::after` 扩展热区的指针图形（`.chev` / `.item-chev`）。
