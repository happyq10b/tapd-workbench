## 二、根目录应有的形状（目标态）

```
E:/WB缓存/2026-10-26-15-55-08/
├── README.md                 ← 根目录唯一"说明书"（含交接文档入口）
├── HANDOFF.md                ← 交接文档唯一入口（三层披露结构）
├── 同步开关.bat / 服务开关.bat  ← 用户操作入口（人的，不动）
├── 工作转移手册.md            ← 长期记忆（建议入库，位置不动）
├── docs/                     ← 全部文档
│   ├── handoff/              ← 交接机制：全量索引 + 归档正文区
│   │   ├── INDEX.md
│   │   └── records/R00NN-*.md
│   ├── 交接记录文档管理方案.md
│   ├── 根目录梳理.md
│   └── …（业务文档：调试指南 / 交付流程规范 / 组织架构设计 …）
├── ops/                      ← 功能区（不归管家管）
├── src/                      ← 代码区（独立仓库，不归管家管）
├── archive/                  ← 只读归档（不归管家管）
└── .workbuddy/memory/        ← 会话记忆
```

**规矩三条**：

1. **根目录只放"入口"** —— 说明书（README）、交接载体（HANDOFF）、用户的两个开关。
   其余文档一律进 `docs/`；
2. **交接类内容统一归 `docs/handoff/`** —— 全量索引、归档正文、机制方案、梳理清单；
3. **不留"影子真相"** —— 根目录每个文件要么入库、要么在 `.gitignore` 里显式说明为什么
   （如 `HANDOFF.md.bak`）。**既没入库、也没说明的文件 = 下次会话就会丢。**

它已被 `.gitignore` 的 `HANDOFF.md.bak` 规则排除，不入库、不会污染仓库。
