## 零、先回答那个问题：改代码在哪改？

### 结论：**改本地 `src/`，不要直接改服务器。**

服务器上确实有 vim/nano，文件也是可写的，但**直接改服务器有三个具体的坑**：

| 坑 | 后果 |
|---|---|
| `sync.sh` 是单向覆盖 | 你在服务器改的内容，下次同步被本地版本**静默覆盖，直接没了** |
| 服务器没有 git | 改错了没法回滚，线上就是事故现场 |
| 改的就是生产 | 没有测试环节，改崩了直接影响所有人用 |

**但现在不用怕了**——我已经加了保护机制：

- `sync.sh` 每次执行前会比对本地与服务器的 `app.py` 校验值，**不一致就拦下来问你**，不会闷头覆盖
- 万一你已经在服务器上改了，`./sync.sh --pull` 可以把改动完整拉回本地并自动提交 git

所以：**改本地 → 推上去**是主流程；**服务器上临时改了**也有兜底路径。

```

./ops/sync.sh --dev          ← 推到服务器热重载，用真数据再验一遍
   ↓ 没问题
./ops/sync.sh --prod         ← 切回生产
```

## 三、同步脚本

```bash
cd E:\WB缓存\2026-10-26-15-55-08\ops

./sync.sh              # 同步代码 + 重启生产服务（数据库不动）
./sync.sh --dev        # 同步代码 + 切开发模式（热重载）
./sync.sh --prod       # 同步代码 + 切回生产模式
./sync.sh --pull       # 从服务器拉回代码（只拉不推）→ 自动 git 提交
./sync.sh --db-local   # 连数据库一起覆盖（危险，会丢服务器新数据）
```

### 覆盖保护

每次同步前自动比对本地与服务器的 `app.py` md5：

```
⚠ 警告：服务器代码与本地不一致
  如果你在服务器上改过，请先执行 ./sync.sh --pull 拉回本地
  否则本次同步会用本地版本覆盖服务器改动

  仍要继续覆盖？(yes/no)
```

输入 `no` 直接取消，服务器改动保住。输入 `yes` 才覆盖。

### 行尾自动转换

Windows 编辑器容易写入 CRLF，`sync.sh` 会在传输前自动转成 LF（会打印 `[LF转换] xxx`）。仓库里也配了 `.gitattributes` 兜底。

| `tapd version` | 看版本与依赖 |

如果确实需要直接改服务器：

```bash

```

**改完必须拉回本地**，否则下次同步会覆盖掉：

```bash

```

## 五、版本管理

本地 `src/` 是 git 仓库：

```bash
cd src
git log --oneline          # 看历史
git status                 # 看当前改动
git diff                   # 看具体改了什么
git checkout -- app/app.py # 撤销单个文件的改动
git revert <commit>        # 撤销某次提交
```

**每次改动记得提交**，提交说明写清楚改了什么，出问题好回溯：

```bash
git add -A
git -c user.name="workbuddy" -c user.email="workbuddy@local" commit -m "修复卡片编辑锁超时判断"
```

> `.gitignore` 已排除 `app.db`、`venv/`、`__pycache__/`、`data/`——数据库不进版本库。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 改了代码没生效 | 生产模式要 `tapd restart`；开发/本地模式自动重载 |
| `sync.sh` 提示服务器不一致 | 说明服务器被改过，先 `./sync.sh --pull` |
| `--pull` 后 git 提交空 | 没检测到变更，正常 |
| 8000 端口占用 | dev 与生产用 systemd `Conflicts` 互斥，不会冲突 |
| 数据不对 | `tapd backups` 找备份 → `tapd restore <文件>` |
| WebSocket 断（协作锁失效） | `tail -f /var/log/nginx/tapd.error.log` |
| 中文乱码 | LANG 已设 C.UTF-8；HTML 是 LF 行尾 |
| 本地 venv 装不上包 | 用 `D:\py\python.exe`（3.14，清华源），已装 paramiko/websockets |
| pip 自升级报错 | pip 25+ 禁止自我升级，用 `python -m pip` 即可 |
| ssh 连不上 | 密码登录已关，必须用密钥：`ssh -F ops/secrets/sshcfg tapd` |
