  getBoundingClientRect 探针（dir/inView/宽高）一次跑通实证。

## #87 · 同步开关中文乱码修复
- 根因：用户终端（WorkBuddy 类）按 UTF-8 渲染字节流，bat 却强制子脚本
  输出 GBK（PYTHONIOENCODING=gbk + iconv）→ 全乱；ANSI 颜色码不解析 VT 原样漏出。
- 修复：PYTHONIOENCODING=utf-8 + NO_COLOR=1（verify.py/sync.sh 尊重）+ 移除 iconv/Drain。
- 教训：①「cmd echo 正常 + Python 输出乱」= 终端按 UTF-8 渲染（echo 走
  WriteConsoleW 不受代码页影响）——这是判据不是巧合；②子进程输出编码要跟
  终端渲染假设对齐；③ANSI 颜色必须尊重 NO_COLOR（no-color.org 约定）。
