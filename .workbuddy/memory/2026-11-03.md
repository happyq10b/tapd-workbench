## 15:2x · UI设计师 · 记录 #37 —— 主页按钮靠右 + 统计卡底边对齐 + 公告字体 + 搜索栏加宽

用户附 4 张截图提 4 项。

### ① 主页按钮靠右 —— 一行 CSS

`.tree-dept` 已是 `inline-flex` 且作为 grid item 撑满 303px 列宽，
但 `.dept-home` 用 `margin-left:2px` 紧跟部门名 → 右边空 146~159px。
→ `margin-left:auto` → 距右缘 **16px**（= padding 14 + 边框 1 + 取整 1），六格成列。

**教训**：flex 子元素「推到某一边」永远用 `auto` 外边距，别手动算 padding。

### ② 统计卡底边对齐「可选看板」底边 —— 根因在 grid 的空行

`.topbar` 两列 grid，`align-items:stretch` → 左右都拉到 topbar 底。
但 `.topbar-main` 是 grid 且声明 `grid-template-rows:auto auto auto`，
**实际只有 1 个子项**（`.tb-navgroup`）→ **末尾凭空多出 2 个空行的 gap（10×2=20px）**；
`.tb-navgroup` 自身 `padding-bottom:13px` + 1px 边框
→ 「可选看板」带底比 topbar 底高 **34px**。

→ `.topbar` 上定义 `--topbar-aside-bottom-offset:34px`，
  `.topbar-aside` 加 `margin-bottom:var(...)`。
grid item stretch 时内容盒 = grid area − margin → 右半 317−34=283，统计带底落在 358。

实测：**统计带底 − 看板带底 = 0px**（改前 34）。

💡 **更优解（本次未做，留给后人）**：把 `.topbar-main` 的
