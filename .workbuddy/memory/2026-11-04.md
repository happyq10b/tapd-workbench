## 18:55 · 主设计师 · 看板卡片布局调整（#58）

用户截图反馈：①板块目录字段与事项内字段未一一对齐；②进度条太长；③进度条要移到负责人
左侧并紧贴，多余空间给标题。

**根因**：#57 把进度条做成板块行 fcols 的**第一格**（独立模板 192px 118px 104px 104px
= 542px）→ 板块字段区比事项行宽 96px、起点差 96px → 视觉上「板块字段整体右移一格」。

**改法**：
- 板块行 fcols **改回与事项行完全同构**（96/118/104/104 = 446px）；
  板块无周数 → **第一格（周数位）复用为进度条位**。
- 进度条 200px → **60px**（30%），格内右对齐 + margin-right:-4px → 距负责人列 4px。
- 标题 392px → **488px**。

**实测**：板块 fL 762 / 事项 760（差 2px 既有基线）；负责人列 866 vs 864（对齐）；
barW 60；barR 862 → owner 866（间距 4px）。

**教训**：两行（板块行/事项行）用 grid 做字段列时，**列模板必须完全同构**，
否则右端锚点相同但左端错位 → 视觉上"字段整体移了一格"。
另：断言文案里的 `%` 会和 Python 的 `%` 格式化冲突 → 写"三成"而不是 "30%"。

**验证**：ui_check_hp_feat 21/0、ui_check_row_layout 22/0；JS 12 组 / UI 17 组全绿。
