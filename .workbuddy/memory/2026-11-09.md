
## #97 · 子事项周数生效 + 布局统一
- 「改了没生效」观感根因 = SUBTREE_CACHE 永不清缓存：reload 重绘后子树
  仍渲染旧值（库已写入）。修复 = reload 开头清缓存。
- applyOwnerSlot 搬移 hack（负责人塞周数行/参与人整行藏）移除，两模式同布局。
- 教训：①「未生效」类反馈先分清**库没写**还是**界面显示旧值**——本次库
  一直是好的，界面缓存背锅；②headless CDP 对 openDetailEdit 弹窗可见性
  时序不稳定（同链路首轮成功后轮不行），此类探针失败先怀疑环境而非代码，
  以库状态+真实浏览器为准。

## #98 · 点击子事项即刻弹出
- 根因：async 函数同步段只有 API 发起，弹窗显示在 4~6 个串行 API 之后。
- 修复：同步帧亮壳（openSubModal 第一行 display=flex+加载中）+ 串行 API 并行化。
- 教训：①「async onclick」的 UI 反馈必须在第一个 await 之前同步给出，
  否则用户必反复点击；②headless 探针若「直接调函数」会绕过 onclick 事件
  路径——复现用户点击问题必须 element.click()；③探针反复失败时先写最小
  决定性实验（正确拼接选择器+三读时序），别在复杂脚本上打补丁。
