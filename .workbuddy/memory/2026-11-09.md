## #113 · 单点登录策略修订（先在线者占位）
- WS 死连接治理三方案对比（实测）：①login 里 send 探活 → 与 receive
  循环并发冲突误杀活连接（全登录被拒事故）；②wait_for receive + 空闲
  超时 → uvicorn/websockets 对 RST 不抛 disconnect（无效）；③last_seen
  + 后台 reaper（零 send）→ ✅ RST 后 0.2s 感知。
- **教训：async 函数忘 await → coroutine truthy → 恒 409 全登录被拒**。
  async 判定必须显式 await。
- websockets 库优雅 close 的服务端感知延迟可达 6s+；真实关浏览器 = 进程
  退出 = RST → last_seen/reaper 路径 0.2s 感知。
