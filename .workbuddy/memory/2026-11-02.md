### 根因与修法

**① 浮空圆点** —— 那是「个人状态栏」的状态点 `.my-status-bar .ms-dot`。
个人状态栏 HTML 带 `hidden` 属性（状态文字为空时 JS 设 `bar.hidden=true`），
但 CSS `.my-status-bar{display:flex}` **优先级高于浏览器 UA 对 `[hidden]` 的
`display:none`** → hidden 形同虚设 → 状态文字被 `.ms-text:empty{display:none}`
藏掉，只剩圆点孤零零浮在左上角。
修法：补 `.my-status-bar[hidden]{display:none}`。
💡 通用经验：元素同时写 `display:flex/grid` 又用 `hidden` 控制显隐时，
**必须**补 `[hidden]{display:none}`（项目里已有 8 处同类兜底）。

**② 标题** —— `.tb-band-title` 改 `font-size:13px;font-weight:700`，
竖条 `::before` 同步加高到 13px。「板块」→「可选板块」。

**③「全部负责人」下拉下线** —— 它与「👤 人员」都作用于 owner 字段，功能重复。
- HTML 删 `<select id="ownerFilter">`；JS 清 `renderProgress()` 的动态填充、
  `reload()` 的 `ps.set('owner')`、`syncFilterHint()` 的负责人分支；
- **「无负责人」不能跟着丢** → 并入人员面板作固定第一条候选项，
  哨兵 `__no_owner__`（前端常量 `OWNER_NONE` + `personLabel()` 显示中文）；
- 后端 `/api/cards` 的 person 分支扩展为识别 `__no_owner__`
  （`want_none` → 匹配 owner 为空/纯空白）；owner 参数保留给外部 API 调用方；
- ⚠️ 架构树回填要**排除** `__no_owner__`（不是真实人员，永远匹配不上），
  但勾选人员时要**保留**它。

**④ 筛选栏同行** —— `.toolbar-left` 改 `flex-wrap:nowrap`；
`.cf-field` 150→104px（max 420→220）；`.cf-input` min 110→52px；
`.filter-date` 140→122px；`.date-filter` 加 `flex:0 0 auto`；
`.search-input` min 140→100 / flex 1 1 150px / max 280→230；
`#filterHint` 加 max-width 260 + 省略号。窄屏 ≤1024px 恢复 wrap 防溢出。
实测 1600px 视口：6 个子元素中心线 y 完全一致（rowSpread=0），不与右侧按钮组重叠。

### 🔴 踩到的坑

- **测试写死日期 → 假性失败**：`test_copy_week.py` 写死「副本周数 = 2026年第44周」，
  但副本 `created` 取**服务端当前时间** → 过了那一周必失败（今天 11-02 已是第 45 周）。
  修法：动态算 `week_label(datetime.now())`；只有**夹具**固定数据才写死周号。
- **断言「源码里没某词」会被注释误伤**：注释里提到「全部负责人」也命中。
  改为针对**元素结构**断言（`<select class="filter-select" id="ownerFilter"`）。
- **CDP 测「是否同一行」要用中心线**（`y + height/2`），不能直接比 `y` ——
  不同高度控件 `align-items:center` 对齐时 y 天然不同。
- **`setLet` 用 JSON 序列化传不了 Set**：`vm.runInContext("PERSON_SEL=new Set([...])", sandbox)`。
