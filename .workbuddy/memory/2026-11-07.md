
## #89 · 三环境开发发布流程框架
- 独立 dev 环境：/opt/tapd-dev + 8001 + nginx 8443（云防火墙白名单放行）→
  https://123.207.252.195:8443；prod/dev 完全独立可同跑。
- tapd 工具箱 v2：stop/start(prod|dev)、snap/rollback（回滚前自动再拍快照）、
  devdb-sync（sqlite backup API，prod 不停服）；归档 ops/server/ 可复现。
- sync.sh --prod 顺序缺陷修复：确认→快照→停服→推码（原「先推码后确认」
  取消时会把半新代码留在 prod 盘）；--db-local 锁定仅 dev。
- 教训：①python io.open(...,'w') 在 Windows 会把 \n 写成 CRLF——写服务器
  脚本必须 newline='\n'（否则 scp 上去 shebang 报 '\r'）；②工具箱子命令
  走 srv-ctl.py 单参转发，bat 菜单零 SSH 细节；③云防火墙白名单制下，
  服务器自身 curl 公网必失败——status 自测只放本机健康。
